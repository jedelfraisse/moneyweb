# MoneyWeb

MoneyWeb is a personal finance tracking application built with .NET Aspire, Blazor, and SQL Server. It helps users manage loans, track debts, schedule payments, and analyze cash flow with a clean, user-friendly interface.

## Features
- 🔁 Recurring bill management
- 💸 Debt and loan tracking (incoming/outgoing)
- 📅 Payment scheduling
- 📊 Cash flow visualization

## Tech Stack
- .NET Aspire · ASP.NET Core · Blazor
- SQL Server · Dapper · FluentMigrator
